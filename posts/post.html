รวม Error Code แอร์ยี่ห้อดัง และวิธีแก้ไขเบื้องต้นด้วยตัวเองก่อนเรียกช่าง

AL

โดย ทีมช่าง AirLux

ผู้เชี่ยวชาญด้านระบบความเย็น แม่ริม เชียงใหม่

เคยไหมครับ? กำลังจะนอนสบายๆ แต่แอร์เจ้ากรรมดันหยุดทำงาน แถมมีไฟกระพริบที่หน้าเครื่อง หรือโชว์รหัสแปลกๆ บนรีโมท อย่าเพิ่งตกใจไปครับ รหัสเหล่านั้นเรียกว่า Error Code ซึ่งเป็นระบบวินิจฉัยตัวเองของแอร์รุ่นใหม่ๆ เพื่อบอกเราว่า "เขากำลังเจ็บป่วยตรงไหน"

วันนี้ AirLux จะพาไปทำความรู้จักกับ Code ยอดฮิตที่พบบ่อยในเชียงใหม่บ้านเราครับ

1. สังเกตอาการเบื้องต้น

ก่อนจะดูรหัส ให้ลองเช็คสิ่งเหล่านี้ก่อนครับ:

  • เบรกเกอร์แอร์สับลงหรือไม่?
  • รีโมทแบตเตอรี่หมดหรือเปล่า?
  • ฟิลเตอร์แอร์ตันจนลมไม่ออกไหม? (ถ้าตันมาก แอร์บางรุ่นจะตัดการทำงานทันที)

2. ตาราง Error Code ยอดนิยม

ยี่ห้อ Code ความหมาย / วิธีแก้
Daikin U2 แรงดันไฟฟ้าผิดปกติ (พบบ่อยในแม่ริมเวลาไฟตก)
Mitsubishi E6/E7 การสื่อสารระหว่างคอยล์ร้อนและเย็นผิดปกติ
Samsung C4 เซ็นเซอร์แลกเปลี่ยนความร้อนมีปัญหา

3. เมื่อไหร่ที่ต้องเรียกช่างมืออาชีพ?

หากคุณลอง Reset เครื่องโดยการปิดเบรกเกอร์ทิ้งไว้ 5 นาทีแล้วเปิดใหม่ แต่ Code ยังกลับมาแสดงเหมือนเดิม นั่นหมายความว่าระบบภายในอาจมีปัญหา เช่น บอร์ดพัง หรือน้ำยาแอร์รั่วครับ

ข้อควรระวัง: ไม่ควรแกะเครื่องหรือเช็คระบบไฟด้วยตัวเองหากไม่มีความชำนาญ เพราะอาจทำให้บอร์ดลัดวงจรและเสียค่าซ่อมแพงกว่าเดิมครับ

เช็ค Code แล้วแก้ไม่หาย?

ส่งรูปถ่าย Error Code มาให้เราช่วยประเมินอาการเบื้องต้นได้ฟรีผ่าน Line ครับ
